# The Crusty Crab – Web Prototype (white theme)

Plain HTML/CSS/JS – no build step.

1. Unzip and open the folder in Visual Studio Code (File > Open Folder).
2. Install the "Live Server" extension, right-click `index.html`, choose "Open with Live Server".
   (Or just double-click `index.html`.)

Pages: index, menu, customise, checkout, feedback, kitchen, admin, tracker.
Colours are CSS variables at the top of `css/styles.css`.
